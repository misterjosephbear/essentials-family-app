## Context Navigation

Before reading raw source files to answer a "how does X work" / "how does X connect to Y" question, check layers in this order — each is cheaper than the last:

1. `~/vault/projects/essentials-family-app-standalone/graphify/graph.json` or `~/vault/projects/essentials-family-app-standalone/graphify/wiki/index.md` — code structure and connections as a queryable graph, generated by [graphify](https://github.com/Graphify-Labs/graphify). Regenerate with `graphify extract . --code-only && graphify cluster-only . --no-label` from this repo, then `graphify export obsidian --graph graphify-out/graph.json --dir ~/vault/projects/essentials-family-app-standalone/graphify` (a git post-commit hook also keeps `graphify-out/graph.json` current automatically).
2. `~/vault/projects/essentials-family-app-standalone/` — decisions, progress, and context notes (see Persistent Memory above).
3. Raw source files — only if the first two layers don't answer the question.

Note: this repo carries `release.keystore`/`release.keystore.b64` (Android signing key material). They're already gitignored — never read, print, or commit their contents.
