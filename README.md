# Essentials Family App

A family essentials tracking app for managing chores, allowance, and savings goals.

## Features

- **Chore Management**: Track daily, weekly, and one-time chores
- **Photo Proof**: Require photo verification for completed chores
- **Allowance Tracking**: Automatic allowance calculation based on completed chores
- **Savings Goals**: Help kids track progress towards savings goals
- **Device Admin**: Optional app blocking for accountability
- **Auto-Updates**: Seamless updates via GitHub releases

## Setup

1. Install the app from [GitHub Releases](https://github.com/misterjosephbear/essentials-family-app/releases)
2. Configure server connection in Setup screen
3. Log in with family member credentials
4. Start tracking chores!

## Requirements

- Android 8.0 (API 26) or higher
- Isaac's Hub Server v25 or later

## Development

```bash
./gradlew assembleDebug
./gradlew installDebug
```
